# Taste

## Workflow
- Don't run terminal commands (install, dev, build, test, git, migrations, scripts) automatically. Explain why the command is needed, show the exact command and expected result, and ask the user to run it and share the output. Never claim a command succeeded without the output. Confidence: 0.7
- Work in small, complete milestones. Finish the files for one milestone, say how to verify it, then wait for the user's review before starting dependent work. Make small, targeted edits instead of regenerating files. Confidence: 0.6

- Keep the project's Markdown build guide/tracker current: read it fully before starting, update it after every milestone based on inspected evidence, and report what is completed, verified, remaining and blocked. Continue only with the next unfinished milestone. Confidence: 0.6

## Communication
- Explain technical steps in simple English, and don't assume knowledge of tool permission modes or terminal behavior. Confidence: 0.5
